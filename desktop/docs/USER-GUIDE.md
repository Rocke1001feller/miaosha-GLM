# Coding Plan Assistant 使用指南（用户版）

把 Kimi Code、小米 MiMo、MiniMax、火山引擎四个平台的额度用量钉在你的 macOS 菜单栏、浮层和桌面浮窗上。数据由配套 Chrome 扩展抓取后只经本机回环（127.0.0.1）推送，不出你的电脑。

## 你需要拿到两个文件

- `CodingPlanAssistant-<版本>.zip`（macOS 菜单栏 app）
- `coding-plan-assistant-web-<版本>-chrome.zip`（配套浏览器扩展，本仓 `web/` 目录）

获取途径：团队内部分发链接 / GitHub Releases 页面（具体地址询问分发者）。

## 安装三步

### 第 1 步：安装菜单栏 app

1. 解压 `CodingPlanAssistant-<版本>.zip`，把 `CodingPlanAssistant.app` 拖进「应用程序」文件夹（/Applications）。
2. **首次运行前**打开「终端」执行（去除下载隔离标记，只需一次）：

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodingPlanAssistant.app
   ```

   也可以在「应用程序」里右键 Coding Plan Assistant → 打开 → 在弹窗中选「打开」，效果相同。
3. 启动 Coding Plan Assistant。它没有 Dock 图标，运行后只出现在屏幕右上角菜单栏（显示形如 `Kimi 24%` 的用量）。
4. 可选：点菜单栏图标 →「设置…」→ 勾选「登录时启动」；若系统提示需批准，到 系统设置 → 通用 → 登录项与扩展 中允许 Coding Plan Assistant。

### 第 2 步：安装配套 Chrome 扩展

1. 解压 `coding-plan-assistant-web-<版本>-chrome.zip`，得到一个文件夹（建议放到固定位置，如 `~/Extensions/coding-plan-assistant-web`，**不要放下载目录后随手删掉**——Chrome 每次启动都要读它）。
2. Chrome 地址栏输入 `chrome://extensions` 回车，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择刚才解压的文件夹。扩展图标（Z 字样「秒杀助手」）出现在工具栏。

### 第 3 步：配对（app ↔ 扩展，只需一次）

1. 点菜单栏的 Coding Plan Assistant 图标 →「设置…」→ 在「桥配对」分区点「复制」令牌。
2. 在 Chrome 里右键扩展图标 →「选项」（或扩展详情页 → 扩展程序选项），找到「Coding Plan Assistant 桥配对」：勾选启用、粘贴令牌、保存（端口保持默认 17389）。
3. 90 秒内，菜单栏、浮层、浮窗就会出现四个平台的真实用量。

## 日常使用

- **菜单栏**：显示 5 小时细粒度用量最高的平台（如 `Kimi 24%`），点击展开四平台完整卡片（浮层）。
- **桌面浮窗**：与菜单栏显示同一平台；左右箭头手动切换（菜单栏跟着切），下次数据刷新自动回到用量最高平台；2 秒无操作收缩为小圆球，点球展开；可拖动、右键菜单调置顶/透明度/点击穿透。
- **配色**：默认「新粗野」（平台撞色 + 粗黑边硬影）。设置页 →「外观」可切换「瑞士排版」（白底黑字超大数字）或「系统」（磨砂 + 绿/黄/红三档色），即时生效。菜单栏文字受 macOS 限制，各模式下都是单色。
- **刷新**：扩展每 60 秒自动推送一次（临近额度重置窗口加速到 30 秒）；浮层底部也有「刷新」按钮。
- **浏览器没开时**：app 会直读 Chrome cookie 尽力刷新（MiniMax/小米/火山可用；Kimi 因凭证存于网页内，显示「需打开浏览器」——这是预期行为，打开一次 Chrome 并访问对应控制台即恢复）。
- **退出 Chrome 超过 10 分钟**：卡片标记「数据已过期」；重开浏览器后自动恢复。

## 常见问题（FAQ）

- **双击 app 没反应 / 提示已损坏**：没有做第 1 步第 2 条的去隔离（xattr）。执行后再开。
- **菜单栏有图标但四张卡都是「等待数据」**：检查第 3 步配对是否完成、令牌是否一致；再到 `chrome://extensions` 确认扩展已启用。
- **小米 / 火山显示「会话已过期」**：浏览器完全退出后这两家的会话 cookie 会失效，扩展会在下一次刷新时自动打开一次后台标签页重新登录（你需保持该平台网页账号是登录状态），一般 1–2 分钟内自愈；不行就手动打开一次对应控制台页面。
- **Kimi 显示「未捕获到 access_token」**：打开一次 `kimi.com` 控制台页面即可（扩展会自动捕获）。
- **菜单栏为什么不显示周用量了**：v1.1 起菜单栏只显示最细粒度（5 小时窗口）用量，周用量在浮层卡片里看。
- **卸载**：退出 app 后删除 `/Applications/CodingPlanAssistant.app`、`~/Library/Application Support/CodingPlanAssistant`，并在 `chrome://extensions` 移除扩展。

## 隐私

桥服务只监听本机回环（127.0.0.1）并用令牌鉴权；用量数据不离开你的电脑；app 只在「扩展长时间不推送」时才直接访问各平台官方接口（等价于你浏览器里的会话），不向任何第三方发送数据。
